## rust-port-scanner

Usage: rps.exe [OPTIONS] --ip <IP>

Options:
-i, --ip <IP>             IP address to scan
-p, --print-descriptions  Print port number descriptions, if available
-h, --help                Print help
-V, --version             Print version
